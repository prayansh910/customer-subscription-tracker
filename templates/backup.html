Database safety

  • Login is required for all application pages.
  • Passwords are stored as hashes, not plaintext.
  • Sessions use HttpOnly/SameSite cookies; production cookies require HTTPS.
  • CSRF protection is enabled for state-changing forms.
  • Assignment history is never overwritten when a customer changes parent.
  • For Render PostgreSQL, use Render's managed recovery/backups in addition to downloading application backups.
